# Resume Matcher

An AI-powered resume matching application that analyzes a candidate's resume against a job description and provides a relevance score along with matching insights.

## Features

* Upload and process resumes
* Compare resumes with job descriptions
* Extract relevant skills and information from resumes
* Generate a resume–job match score
* Identify relevant and missing skills
* Interactive frontend interface
* Backend API for resume processing and matching

## Tech Stack

**Frontend**

* HTML
* CSS
* JavaScript

**Backend**

* Python
* FastAPI

**AI / NLP**

* Natural Language Processing
* Text similarity / semantic matching

## How It Works

The application processes the uploaded resume and job description, extracts relevant information, and compares them to determine how well the candidate's profile aligns with the given role.

The system analyzes factors such as skills, experience, and relevant keywords to generate a **resume–job match score** and provide useful matching insights.

## Example

> Python, FastAPI, SQL, Machine Learning, REST APIs

**Job Description**
